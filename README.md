# ***C++ Discord WebHook Wrapper***

#### - This is a Discord WebHook library made in ***c++***, It is a lightweight, performative, library for sending messages,files,photos,videos,etc to discord  

#### - This May Have some bugs to it. if found please make a request to it. 
---

# ***Features Of WebHook Library***

#### - ***Zero Dependence***: This library works with `libcurl`,so there is no library overhead for this library

#### - ***Fast***: This library is really fast because this is written in c++, ***this code is still in development so it may contain some bugs affecting speed.*** 

## How to Use WebHook Library
#### To use this library make a program using the example code given in the `/src/main.cpp` and then using cmake build the ***output file***. It will be named ***`Send`*** and execute the program 

#### You can see the message and the file appearing in the discord channel
